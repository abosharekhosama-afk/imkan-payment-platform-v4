## Scripts

| Script | Purpose |
|---|---|
| `npm run ops:pg-backup` | Logical SQL dump of public tables |
| `npm run ops:pg-restore -- --file <path> [--wipe]` | Restore dump (`--wipe` truncates data first) |
| `npm run ops:pg-backup-drill` | Embedded PG A→backup→B restore verification |

## Environment

- `DATABASE_URL_PG` — PostgreSQL connection string (required)
- `BACKUP_OUT_DIR` — optional backup output directory
