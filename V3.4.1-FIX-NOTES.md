# V3.4.1 Fix Notes

This build fixes the V3.4 login/session failure caused by an invalid MySQL placeholder in `createSession()`.

## Main fixes
- Fixed `POST /v1/auth/login` session creation.
- Session expiry interval is now validated and embedded as a safe integer in the SQL statement.
- Fixed dashboard analytics queries using dynamic `INTERVAL` values.
- `/v1/auth/me` now returns the active merchant id for the authenticated tenant.
- Added a friendlier database error message for SQL parse/parameter-count failures.
- Preserved the V3.4 Arabic/English toggle, RTL layout, hidden sidebar scrollbar, and mobile navigation.
- Version bumped to 3.4.1.

npm install
npm run db:migrate
npm run dev
